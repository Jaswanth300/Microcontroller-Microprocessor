## 📖 Executive Summary

This repository houses the complete, faculty-verified laboratory coursework for **ECA1011 — Microprocessors and Microcontrollers**. It contains modular implementations spanning low-level assembly language programming and embedded control across the **Intel 8085**, **Intel 8086**, **Intel 8087 Math Coprocessor (FPU)**, **Intel 8051 Microcontroller**, and **Microchip PIC18F45K22** architectures.

Every experiment includes:
1. **Source Code (`.asm` / `.mpc` / `.c`)**: Fully commented, modular assembly routines with register allocations and input/output definitions.
2. **Simulation Evidence (`.png`)**: Authentic execution captures using the **Microprocessor 8085 Simulator Software Kit 1.0**, **emu8086**, **Keil μVision IDE**, and **Proteus Simulation Software**.
3. **Formal Lab Reports (`.docx`)**: Comprehensive academic reports featuring objectives, algorithms, flowcharts, source listings, data mapping tables, and discussion of results.
4. **Master Consolidated Record**: An all-in-one laboratory document indexing all experiments with institutional title page, syllabus mapping, and faculty verification spaces.

## 🔬 Detailed Experiment Breakdown

<details>
<summary><b>🔹 Experiment 1: 8-bit & 16-bit Arithmetic Operations (Intel 8085)</b></summary>

- **Core Concepts:** Direct and indirect addressing modes, accumulator operations, carry flag propagation, double-register arithmetic (`DAD`), iterative division and multiplication.
- **Routines Implemented:**
  - `A1_8bit_Addition.mpc` & `A2_8bit_Subtraction.mpc` — 8-bit addition with carry handling and subtraction with borrow.
  - `B1_16bit_Addition.mpc` & `B2_16bit_Subtraction.mpc` — 16-bit addition using `DAD B` / `ADC` across register pairs `HL` and `BC`.
  - `C1_8bit_Multiplication.mpc` & `C2_8bit_Division.mpc` — Successive addition multiplication and successive subtraction division.
  - `D1_16bit_Multiplication.mpc` & `D2_16bit_Division.mpc` — Extended precision 16-bit algorithms.
- **Files:** [Experiment 1 Folder](LAB/Experiment_1/)

</details>

<details>
<summary><b>🔹 Experiment 2: Logical, Bit-Manipulation & Shift Operations (8086 / 8085)</b></summary>

- **Core Concepts:** Boolean bitwise logic, selective bit masking, parity/zero flag evaluation, arithmetic and logical shift/rotate operations for bit stream manipulation.
- **Routines Implemented:**
  - `ProgA_Logical_Bitwise.asm` — Bitwise `AND`, `OR`, `XOR`, and `NOT` operations on 8-bit and 16-bit operands with status flag tracking.
  - `ProgB_Shift_Rotate.asm` — `SHL`, `SHR`, `RCL`, `ROR` fast arithmetic multiplication/division by powers of 2.
- **Files:** [Experiment 2 Folder](LAB/Experiment_2/)

</details>

<details>
<summary><b>🔹 Experiment 3: Multi-Byte Data & Array Operations (8086 Indirect Addressing)</b></summary>

- **Core Concepts:** Multi-byte arithmetic, array traversal using base-index indirect addressing (`[SI]`, `[DI]`, `[BX+SI]`), loop counters, sum accumulation and average calculation.
- **Routines Implemented:**
  - `ProgA_MultiByte_32bit_Addition.asm` — 32-bit addition propagating carry across successive 16-bit words.
  - `ProgB_Array_Sum_Average.asm` — Traversal of an array of numerical elements in memory, calculating sum and arithmetic mean.
- **Files:** [Experiment 3 Folder](LAB/Experiment_3/)

</details>

<details>
<summary><b>🔹 Experiment 4: String and Block Data Operations (8086 Primitive Objects)</b></summary>

- **Core Concepts:** Dedicated hardware string primitives, direction flag (`DF`) management, repeat prefixes (`REP`, `REPE`, `REPNE`), source (`SI`) and destination (`DI`) pointers with segment overrides.
- **Routines Implemented:**
  - `ProgA_Block_Transfer_MOVSB.asm` — Memory block transfer using `REP MOVSB`.
  - `ProgB_String_Compare_CMPSB.asm` — Byte-by-byte string comparison using `REPE CMPSB`.
  - `ProgC_Character_Search_SCASB.asm` — Linear character searching within a string buffer using `REPNE SCASB`.
  - `ProgD_Case_Conversion_LODSB_STOSB.asm` — ASCII lowercase-to-uppercase translation using `LODSB` and `STOSB`.
- **Files:** [Experiment 4 Folder](LAB/Experiment_4/)

</details>

<details>
<summary><b>🔹 Experiment 5: Factorial, Square, Branch & Subroutine Operations (8086)</b></summary>

- **Core Concepts:** Modular subroutines, stack frame management (`PUSH`, `POP`), parameter passing, iterative and recursive branching algorithms, conditional jump evaluation.
- **Routines Implemented:**
  - `ProgA_Factorial_LOOP.asm` — Factorial computation of an integer $N!$ utilizing loop counters and accumulation in `AX:DX`.
  - `ProgB_Square_Subroutine.asm` — Dedicated procedure (`NEAR CALL`) to compute the square of a number and return results via `RET`.
  - `ProgC_Largest_Smallest_Branching.asm` — Array scan algorithm with conditional branching to determine maximum and minimum elements.
- **Files:** [Experiment 5 Folder](LAB/Experiment_5/)

</details>

<details>
<summary><b>🔹 Experiment 6: Interrupt Handling and Device Programming (8086)</b></summary>

- **Core Concepts:** Interrupt Vector Table (IVT) architecture, calculation of vector addresses ($4 \times \text{Type}$), installing custom Interrupt Service Routines (ISRs), Non-Maskable Interrupt (NMI) configuration, hardware interrupt flags (`IF`).
- **Routines Implemented:**
  - `ProgA_INT40H_Vector_Setup.asm` — Setup and installation of user interrupt `INT 40H` in IVT at memory `0000:0100H`.
  - `ProgB_NMI_INT02H_Vector.asm` — Vector initialization for Type 2 Non-Maskable Interrupt (`NMI`) at `0000:0008H`.
  - `ProgC_Interrupt_Masking.asm` — Demonstration of critical section protection utilizing `CLI` and `STI`.
- **Files:** [Experiment 6 Folder](LAB/Experiment_6/)

</details>

<details>
<summary><b>🔹 Experiment 7: Arithmetic Coprocessor & Floating Point Simulation (8086/8087)</b></summary>

- **Core Concepts:** IEEE 754 single and double precision floating point representation, numeric coprocessor stack architecture (`ST(0)` to `ST(7)`), FPU control and status word evaluation, coprocessor synchronization (`FWAIT`).
- **Routines Implemented:**
  - `ProgA_Float_Arithmetic.asm` — Real number arithmetic using coprocessor instructions (`FLD`, `FADD`, `FSUB`, `FMUL`, `FDIV`, `FSTP`).
  - `ProgB_Area_Circle_FSQRT.asm` — Geometric formula calculation ($\text{Area} = \pi \cdot r^2$ and root calculation using `FSQRT` and `FLDPI`).
  - `ProgC_Compare_Real_Numbers.asm` — Floating-point comparison using `FCOM` / `FCOMP` and transferring condition code bits via `FSTSW AX` / `SAHF`.
- **Files:** [Experiment 7 Folder](LAB/Experiment_7/)

</details>

<details>
<summary><b>🔹 Experiment 11: Serial Communication using 8251 USART and 8253 Timer (8086)</b></summary>

- **Core Concepts:** Asynchronous serial communication protocol, baud rate generation via 8253 PIT (Mode 3 square wave), 8251 USART initialization sequence (dummy zeros, reset, mode, command words), status polling (`TxRDY`, `RxRDY`), character echoing, and communication error checking (`PE`, `OE`, `FE`).
- **Routines Implemented:**
  - `ProgA_USART_Init_Tx.asm` — 8253 counter 0 initialized with divisor `0027H` (39D), 8251 configured in asynchronous mode (1 stop bit, 8 data bits, no parity, 16X), serial transmission of string from memory `1650H`.
  - `ProgB_USART_Rx_Echo.asm` — Polling `RxRDY`, error inspection (`TEST AL, 38H`), storing string to buffer `1700H`, echoing back to serial terminal, and logging error count to `1710H`.
- **Files:** [Experiment 11 Folder](LAB/Experiment_11/)

</details>

<details>
<summary><b>🔹 Experiment 13: 8051 Arithmetic, Logical and Bit-Manipulation Programming (Keil)</b></summary>

- **Core Concepts:** MCS-51 architecture, 8051 ALU operations, hardware multiplication and division (`MUL AB`, `DIV AB`), Program Status Word (`PSW`) flag analysis (`CY`, `AC`, `OV`, `P`), boolean bit manipulation in bit-addressable RAM (`20H`–`2FH`), nibble swapping (`SWAP`).
- **Routines Implemented:**
  - `Prog1_8051_Add_Sub.asm` — 8-bit addition (`ADD`) and subtraction with borrow (`SUBB`) with PSW flag tracking.
  - `Prog2_8051_Mul_Div.asm` — Unsigned 8-bit multiplication (`MUL AB` -> `B:A`) and division (`DIV AB` -> Quotient `A`, Remainder `B`).
  - `Prog3_8051_Logical_Bitwise.asm` — Logical masking (`ORL`, `ANL`, `XRL`), rotates (`RL`, `RR`), nibble swap (`SWAP`), and bit addressing (`SETB`, `CLR`, `CPL`).
- **Files:** [Experiment 13 Folder](LAB/Experiment_13/)

</details>

<details>
<summary><b>🔹 Experiment 14: 8051 Block Transfer, Multi-byte Addition & Lookup Table (Keil)</b></summary>

- **Core Concepts:** Data pointer (`DPTR`) and `MOVX` external RAM access, carry-chain multi-byte addition (`ADDC`), register bank selection via `PSW.3` (`RS0`) and `PSW.4` (`RS1`), stack pointer (`SP`) management with `PUSH`/`POP`, program code-memory table lookup (`MOVC A, @A+DPTR`).
- **Routines Implemented:**
  - `ProgA_8051_Block_Transfer.asm` — Transfer of 5-byte block from External RAM (`4000H`) to Internal RAM (`50H`).
  - `ProgB_8051_4Byte_Addition.asm` — 4-byte multi-byte addition with carry propagation, storing extended 5-byte sum in External RAM (`4500H`).
  - `ProgC_8051_Banks_Stack_MOVC.asm` — Bank switching (Bank 0 vs Bank 1), stack operations, and ROM lookup table square generation (`TABLE: DB 00H, 01H, 04H, 09H...`).
- **Files:** [Experiment 14 Folder](LAB/Experiment_14/)

</details>

<details>
<summary><b>🔹 Experiment 18: Multi-Floor Elevator Controller Simulation (PIC18F45K22 / Proteus)</b></summary>

- **Core Concepts:** Embedded control engineering, Harvard RISC architecture, floor pushbutton interfacing, 4-phase stepper motor driving via ULN2003, LOOK elevator scheduling state machine (`IDLE`, `UP`, `DOWN`, `DOOR`), 7-segment floor display, and status indicators.
- **Routines Implemented:**
  - `Elevator_Controller_XC8.c` — Full C implementation in MPLAB XC8 with request latching, priority servicing, 200 steps/floor motor commutation, and 2-second door delay.
  - `Elevator_Controller_MPASM.asm` — Optimized assembly routine utilizing lookup tables `seg_tab`, `phase_tab`, `bit_mask_tab`, `above_mask_tab`, and `below_mask_tab`.
- **Files:** [Experiment 18 Folder](LAB/Experiment_18/)

</details>
